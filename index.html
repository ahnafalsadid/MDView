Installation

MDView needs no npm, Node.js, React, Vue or build tool.

Download mdview.js and mdview.css, place them beside your index.html, then include them:

<link rel="stylesheet" href="mdview.css">
<script src="mdview.js"></script>

Your first page

Create README.md, then render it:

<main id="markdown"></main>
<script src="mdview.js"></script>
<script>
  MDView.renderFile("README.md", "#markdown");
</script>
Opening via file:/// can block fetch(). Use a local server: python3 -m http.server 8080 or VS Code Live Server.

API

Method Purpose
MDView.render(md, options) Convert Markdown to an HTML string
MDView.mount(target, md, options) Render Markdown into a DOM element
MDView.renderFile(file, target, options) Fetch a .md file and render it
MDView.create(target, options) Create a reusable renderer

mount() & render()

MDView.mount("#markdown", "# Hello");
const html = MDView.render("# Hello");

renderFile()

try {
  await MDView.renderFile("docs/api.md", "#markdown");
} catch (e) {
  console.error(e);
}

create()

const docs = MDView.create("#markdown");
docs.render("# Hello");
await docs.renderFile("README.md");

Options

Option Default Description
gfm true GitHub-Flavored mode (reserved)
breaks false Single line breaks become <br>
allowHtml false Allow raw HTML from Markdown
sanitizeUrls true Block dangerous link protocols
className "mdview-body" CSS class on the container
Only set allowHtml: true for Markdown you fully trust.

Supported Markdown

Headings (auto-generated IDs), paragraphs, bold, italic, strikethrough, inline code, fenced code blocks (language kept as language-js), links, lazy-loaded responsive images, ordered/unordered lists, task lists, blockquotes, horizontal rules, tables with alignment, and autolinks.

Styling & dark theme

Customize .mdview-body with normal CSS. Dark mode follows prefers-color-scheme automatically.

.mdview-body { max-width: 1100px; font-size: 17px; }
@media (prefers-color-scheme: dark) {
  .mdview-body { background: #0b0f14; color: #e6edf3; }
}

Building a docs website

docs-site/
├── index.html
├── mdview.js
├── mdview.css
└── docs/
    ├── introduction.md
    ├── installation.md
    └── api.md
const docs = MDView.create("#markdown");
async function loadDoc(f) { await docs.renderFile(f); }
loadDoc("docs/introduction.md");

Host on GitHub Pages, Netlify, Vercel or Cloudflare Pages. Remote files work when the server sends CORS headers.

Security

Raw HTML is escaped and URLs are sanitized by default, so <img src=x onerror=alert(1)> renders as text.

No Markdown parser is a complete security boundary. For user-generated content, add server-side sanitization and a Content Security Policy.

Troubleshooting

Problem Fix
Wrong path / 404 Check the file exists on the server
Running from file:// Use a local HTTP server
CORS errors Configure the remote server's CORS headers
SPA conflicts Don't let a framework control the same innerHTML
